Audit Autofill

Checking this tab…

  1. Open the new audit (the edit page with the green edit buttons).
  2. In the panel, drop / paste / choose a screenshot of the previous month's View Server Audit page.
  3. Check the list: ticked items are the ones that were green ✓. Untick anything you don't want.
  4. Press Mark … items Active. Everything that wasn't green is left as it is.
